# Contributing to Tutora AI

Thank you for your interest in contributing to **Tutora AI**! We welcome community contributions, bug reports, feature proposals, and translations.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
- Search existing [Issues](https://github.com/MilannSharma/Tutora-AI/issues) to verify if the bug has already been reported.
- If not, open a new issue using our **Bug Report** template.
- Include:
  - Your operating system and version (Windows 10/11, macOS, Linux).
  - Tutora AI version (e.g., v1.4.0).
  - Clear steps to reproduce the issue.
  - Screenshots or screen recordings if applicable.

### 2. Suggesting Features
- Open a feature request via the [Feature Request](https://github.com/MilannSharma/Tutora-AI/issues) issue template.
- Explain the motivation: what problem does this feature solve and how does it benefit walkthrough creation?

### 3. Translations & Localization
Tutora AI supports multiple languages. We welcome community pull requests adding or improving localization strings for:
- English, Hindi, Spanish, French, German, Japanese, and more.

---

## 📜 Code of Conduct
Please be polite, collaborative, and constructive when interacting with fellow contributors and maintainers.
